# 🚀 TUBES STIMA - SATURNUS

## 📌 Deskripsi Project

Project ini merupakan tugas besar (TUBES) mata kuliah **Strategi Algoritma (STIMA)**.  
Bot ini dibuat untuk dapat bermain dalam game dengan cara:

- Mengambil keputusan otomatis
- Menentukan strategi terbaik
- Mengoptimalkan langkah permainan

Bot dikembangkan menggunakan bahasa pemrograman **C#**.

---

## ⚙️ Teknologi yang Digunakan

- 💻 C#
- 🧠 Algoritma Strategi
- 🔧 .NET / CLI
